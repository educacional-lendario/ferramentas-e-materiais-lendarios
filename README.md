## 🛠️ Como Usar

Você pode utilizar qualquer skill deste repositório de duas formas:

1. **No seu chat de IA favorito (ChatGPT, Claude, Gemini):** Dentro da pasta de cada skill, você encontra o arquivo `template-prompt.md`. Basta copiar o prompt, preencher os dados do seu negócio e enviar na conversa.
2. **No terminal (Claude Code, Codex, Antigravity):** Cada pasta contém o arquivo `SKILL.md` pronto para instalação local como comando/skill. Consulte as instruções de cada skill para instalar em um clique.
